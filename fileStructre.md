# .bin File Structure

## 1. `base_vectors.bin`

This file is opened for reading and serves as the initial source of the unclustered data.

| Offset (Bytes) | Data Type | Size (Bytes) | Field / Content | Description |
| :--- | :--- | :--- | :--- | :--- |
| `0 - 3` | `uint32` | 4 | `num_vectors` | Total number of vectors in the dataset. |
| `4 - 7` | `uint32` | 4 | `dim` | Dimensionality of each vector. |
| `8` onwards | `float32[]` | `num_vectors * dim * 4` | Vector Data | A continuous sequence of raw floats representing the vectors. |

---

## 2. `centroids.bin`

This file stores the coordinates of the cluster centroids generated by `MiniBatchKMeans`.

| Offset (Bytes) | Data Type | Size (Bytes) | Field / Content | Description |
| :--- | :--- | :--- | :--- | :--- |
| `0 - 3` | `uint32` | 4 | `num_clusters` | The total number of clusters (hardcoded as `1024`). |
| `4 - 7` | `uint32` | 4 | `dim` | Dimensionality of each centroid. |
| `8` onwards | `float32[]` | `num_clusters * dim * 4` | Centroid Coordinates | A flat array of cluster coordinates (`shape=(1024, dim)`). |

---

## 3. `vectors.bin`

This is the primary inverted index file where vectors are grouped and sorted continuously by their assigned cluster IDs to allow efficient range-based disk queries.

| Relative Offset / Layout Section | Data Type | Calculated Size (Bytes) | Field / Content | Description |
| :--- | :--- | :--- | :--- | :--- |
| **Header Section** | | | | |
| `0 - 3` | `uint32` | 4 | `num_clusters` | Number of clusters (`1024`). |
| `4 - 7` | `uint32` | 4 | `dim` | Dimensionality of the vectors. |
| `8 - 11` | `uint32` | 4 | `num_vectors` | Total number of vectors. |
| **Metadata Arrays** | | | | |
| Next block | `uint32[]` | `num_clusters * 4` | `cluster_sizes` | Number of vectors inside each cluster. |
| Next block | `uint32[]` | `num_clusters * 4` | `cluster_offsets` | The starting vector index inside `sorted_indices` / data payloads for each cluster. |
| Next block | `uint32[]` | `num_vectors * 4` | `sorted_indices` | Mapping of rearranged IDs back to original positions in `base_vectors.bin`. |
| **Payload Section** | | | | |
| Trailing block | `float32[]` | `num_vectors * dim * 4` | Grouped Vector Data | Raw vector coordinate blocks, sequentially written group-by-group based on cluster mapping. |
